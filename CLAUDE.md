# cluood — «Говори Клод»

Лендинг-скролли-опрос про то, что Claude читается «Клод», а не «Клауд».
Одна страница, 13 полноэкранных панелей со scroll-snap, счётчик «клодности» в HUD.

## Указания от владельца проекта

> В будущем прикрутим аналитику. Все должно работать!

- Под аналитику уже подготовлена заглушка [src/analytics.ts](src/analytics.ts):
  типизированные события (`answer`, `quiz_reset`, `quiz_complete`) и функция `track()`.
  Точки вызова по коду расставлены. Прикручивая провайдера (Метрика/GA/Plausible…),
  меняй только реализацию `track()`.
- «Все должно работать» — после любых правок прогоняй `npm run build`
  (включает проверку типов) и проверяй сайт глазами/через `npm run preview`.
- Прогресс работ фиксируется в [PROGRESS.md](PROGRESS.md) — дописывай туда записи о сделанном.

## Стек и структура

- **Vite 7 + TypeScript 5** (strict), без фреймворков и рантайм-зависимостей.
- `index.html` — вся разметка (панели опроса). Инлайновые SVG-мемы оставлены в разметке
  намеренно: их `<text>` использует Google-шрифты страницы, во внешнем файле через `<img>`
  шрифты бы не применились.
- `src/main.ts` — логика опроса (подсчёт, вердикты, скролл, IntersectionObserver).
- `src/style.css` — все стили.
- `src/assets/` — картинки (brain-мемы для `.bi1`–`.bi4`, фото Шеннона).
- `raw/` — исходники, в сборку не попадают (шаблон мема, логотип Anthropic).

## Команды

```
npm run dev        # дев-сервер
npm run build      # tsc --noEmit + vite build → dist/
npm run preview    # раздать dist/ локально
npm run typecheck  # только типы
```

## Особенности поведения (не сломай)

- Панель 01 (`data-nostat`) — ответы не идут в статистику (там подстава: все варианты «Клауд»).
- Панель 08 (`data-gag`) — сначала показывает фейковое «НЕВЕРНО», через 1.6 с — настоящий
  фидбек; неверный ответ через 3.2 с сбрасывает весь прогресс (`resetAll`).
- Везде уважается `prefers-reduced-motion`.
- Тексты на странице — русские, с буквой «ё» и кавычками-«ёлочками»; сохраняй стиль.
