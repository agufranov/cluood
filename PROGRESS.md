## 2026-08-25 — Реорганизация: из одного HTML в проект на Vite + TypeScript

Было: весь сайт в одном `index.html` на 959 строк и 162 КБ — стили, скрипт
и 5 картинок в base64 внутри файла.

Сделано:

- **Сборщик и типы.** Добавлены Vite 7 и TypeScript 5 (strict): `package.json`,
  `tsconfig.json`, `.gitignore`. `npm run build` = проверка типов + сборка.
- **Картинки вынесены.** 5 base64-JPEG декодированы в `src/assets/`
  (`brain-1..4.jpg` — панели мема «expanding brain», `shannon.jpg` — фото Шеннона).
  В сборке ссылки хешируются Vite. Инлайновые SVG (Ван Дамм, кривая, схема Шеннона)
  оставлены в разметке: их текст использует шрифты страницы, во внешнем `<img>` они бы отвалились.
- **Стили вынесены** в `src/style.css` (без изменений, кроме `url()` на файлы картинок).
- **JS переписан на TypeScript** в `src/main.ts`: строгие типы, `const/let`,
  `dataset` вместо `getAttribute`, поведение 1:1 с оригиналом.
- **Заглушка аналитики** `src/analytics.ts`: типизированные события
  `answer` / `quiz_reset` / `quiz_complete`, вызовы уже расставлены по коду,
  в dev-режиме события видны в консоли. Осталось подставить провайдера.
- **Исправлен каркас HTML:** у страницы не было `<!doctype>`, `<html>`, `<head>`,
  `<meta charset>` и `<meta viewport>` — добавлены (viewport важен: медиазапросы
  `max-width:760px` на телефонах без него не срабатывали). Добавлены `preconnect`
  к Google Fonts и `meta description`.
- **Исходники убраны в `raw/`:** `image.png` → `raw/expanding-brain-template.png`
  (шаблон мема, из него нарезаны brain-картинки), `img_to_use/nop.svg` →
  `raw/anthropic-logo.svg`. В сборку не попадают.

Проверено: `npm run build` зелёный; `vite preview` — страница, JS, CSS и все
5 картинок отдаются с кодом 200, base64 в сборке не осталось.
